# NØRVA — Premium Streetwear E-commerce

Modern responsive fashion e-commerce website designed and developed with HTML, CSS and JavaScript.

## Features

- Responsive design
- Product filtering
- Product search
- Product quick view
- Size selection
- Shopping cart
- Dynamic cart total
- Quantity controls
- Mobile navigation
- Newsletter form
- Smooth animations
- Desktop, tablet and mobile layouts

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- SVG

## Project

NØRVA is a fictional premium streetwear brand created as a frontend development project.

## Preview

Open `index.html` in a browser to view the website.
